# Vision Bridge（视觉桥）

此 Skill 让你通过 `vision_analyze` 工具获得图片识别能力。该工具由视觉桥插件提供，调用外部视觉模型（如 SenseNova）识别图片内容，即使当前主模型是纯文本模型也能"看见"图片。

## 核心规则

**永远不要描述你没有通过工具分析过的图片。** 先调用 `vision_analyze` 工具，然后基于返回的文字描述回答。不要猜测、不要根据文件名推断内容、不要编造细节。

## 可用工具

- `vision_analyze(image_path, question?)` — 分析指定路径的图片，返回视觉模型对图片内容的文字描述。
  - `image_path`: 图片文件路径（支持 .png/.jpg/.jpeg/.webp/.gif）
  - `question`: 可选，关于图片的具体提问；省略时默认要求视觉模型详细描述图片内容

## 何时使用

用户要求以下任何一项时，调用 `vision_analyze`：

- 识别或描述图片中描绘的内容
- 读取图片中的文字（OCR），包括中文、英文、代码
- 回答关于图片内容的问题（"这是什么颜色？""图里有多少人？""这个错误信息是什么？")
- 分析截图、UI 界面、图表、文档、照片
- 比较两张或多张图片

## 工作流程

1. **定位文件。** 如果用户给了精确路径，直接使用。如果用户只描述了（如"我桌面上的截图"），先用 `glob` 搜索——用 `*.png`、`*.jpg` 等模式，确认匹配后再调用分析工具。
2. **调用 `vision_analyze`。** 传入文件路径和可选的问题。
3. **分析返回结果，** 然后直接回答用户的问题：
   - *识别*：列出主要物体、人物、场景、颜色和显著细节。
   - *OCR*：忠实转录所有可见文字，保持布局、换行和标点符号。精确引用原文。
   - *描述*：给出结构化摘要——整体场景 → 关键主题 → 可见文字/细节 → 异常或值得注意的点。
   - *比较*：对每张图片调用分析，然后逐点对比。
4. **诚实对待限制。** 如果视觉模型返回的描述中某区域模糊、遮挡或不确定，如实说明并标注置信度。区分明确看到的内容和推断的内容。

## 指引

- 用用户使用的语言回答（如中文请求用中文回复）。
- 对于图表，报告坐标轴、标签、单位和数值；不要编造图中不可见的数字。
- 对于 UI 截图，描述可见的窗口/控件并转录所有文字、错误信息和标签。
- 如果用户要求*编辑*图片，说明此 Skill 只覆盖查看，建议使用其他工具（如 bash 配合图像库）进行编辑。
- 如果涉及多张图片，逐张分析，然后给出综合回答。

## 局限

- 支持的格式：PNG、JPEG、WebP、GIF。
- 此 Skill 仅查看和分析图片；不修改图片。
- 识别结果的质量取决于所配置的视觉模型能力。
- 需要使用视觉桥插件（`@deepseek-ai/dsh-vision-bridge`）注册 `vision_analyze` 工具后才能使用。
